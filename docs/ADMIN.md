# 관리자 사용 안내

## 로그인

운영 환경에서 `/admin` 접속 시 Cloudflare Access 이메일 일회용 인증을 거칩니다. 허용 정책에는 최고관리자 이메일 한 개만 등록합니다.

## 문의

문의번호, 연락처, 내용으로 검색할 수 있습니다. 신규 문의를 완료할 때 처리 결과를 반드시 입력합니다. 완료를 다시 신규로 되돌리는 기능은 제공하지 않습니다.

## 콘텐츠

상품·소식·입점처는 비공개 상태로 작성한 뒤 확인 후 공개하는 방식을 권장합니다. 삭제는 즉시 영구 적용되므로 로컬 원본을 확인하고 진행합니다.

## 이미지

JPG, PNG, WebP를 선택할 수 있으며 브라우저에서 WebP로 최적화됩니다. 파일당 원본 한도는 10MB입니다. 이미지 설명은 검색과 접근성을 위해 필수입니다.
