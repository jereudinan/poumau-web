# 최종 요구사항

## 목적

- 브랜드 신뢰도 강화
- 스마트스토어 구매 유도
- 기관·단체 제휴와 커스텀 제작 문의 확보
- 일반 고객 문의 접수 및 이력 관리

## 공개 메뉴

파우마우 소개, 상품소개, 오프라인, 파우마우 소식, 문의하기로 구성합니다. 메인은 3장 롤링 배너, 대표 상품, 브랜드 소개, 커스텀 안내, 판매 채널, 오프라인, 최근 소식, 문의 CTA 순서입니다.

## 운영 규칙

- 상품 구매는 상품별 스마트스토어 URL로 이동합니다.
- 모든 제품은 문의 후 커스텀 제작을 협의할 수 있습니다.
- 품절 제품은 구매 버튼을 숨기고 문의 버튼만 제공합니다.
- 문의 상태는 신규와 완료 두 단계입니다.
- 완료 시 처리 결과가 필수이며 완료일로부터 3년 뒤 개인정보를 자동 삭제합니다.
- 소식은 분류 없이 게시일 최신순으로 노출합니다.
- 콘텐츠 삭제는 확인 후 영구 삭제합니다.

## 브랜드 표현

- 슬로건: 일상의 가치가 소소한 행복으로
- 검색 표기: 파우마우 | 패브릭 핸드메이드 전문
- 문구: 수익의 일부는 유기동물 구조 단체에 후원금으로 사용됩니다.
- 구체적인 후원 금액, 단체명, 실적은 공개하지 않습니다.
