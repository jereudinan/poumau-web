# 공개 전 개인정보 점검

- [ ] 실제 대표자, 사업자등록번호, 통신판매업 신고번호 입력
- [ ] 개인정보 보호책임자 이름, 연락처, 이메일 입력
- [ ] 개인정보처리방침 시행일 입력
- [ ] Cloudflare 데이터 처리 조건과 국외 이전 관련 문구 검토
- [ ] 문의 보존 기간 3년의 업무상·법적 필요성 최종 확인
- [ ] Access 허용 이메일이 최고관리자 한 명인지 확인
- [ ] 운영 환경에 개발용 인증 우회 변수가 없는지 확인
- [ ] Turnstile 운영 키와 허용 도메인 확인
- [ ] 문의 데이터 접근·변경 로그 확인

기본 방침 문구는 초안이며 실제 사업 형태에 맞춘 법률 검토를 권장합니다.
