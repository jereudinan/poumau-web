# 데이터베이스

초기 스키마는 `migrations/0001_initial.sql`에 있습니다.

| 테이블 | 목적 |
|---|---|
| `products` | 상품, 판매 상태, 스마트스토어 링크 |
| `news_posts` | 소식과 외부 링크 |
| `stores` | 위탁 매장과 네이버 지도 링크 |
| `inquiries` | 문의와 처리 결과 |
| `audit_logs` | 관리자 생성·수정·삭제·업로드 기록 |
| `retention_logs` | 보존 기간 만료 삭제 건수 |

입점처 초기 데이터는 비공개 상태입니다. 주소와 입점 여부를 확인한 뒤 관리자에서 공개해야 합니다.
