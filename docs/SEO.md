# 검색엔진 등록

## 기본 설정

- 페이지별 title, description, canonical, Open Graph
- Organization 구조화 데이터
- `/robots.txt`와 `/sitemap.xml`
- 관리자와 개인정보처리방침은 검색 제외

## 네이버

1. 네이버 서치어드바이저에서 `https://poumau.com` 추가
2. HTML 태그 방식의 소유 확인 값을 레이아웃에 반영
3. `https://poumau.com/sitemap.xml` 제출
4. 주요 페이지 URL 수집 요청

## Google

1. Google Search Console에서 도메인 속성 추가
2. Cloudflare DNS에 확인용 TXT 레코드 등록
3. 사이트맵 제출
4. 색인 생성과 모바일 사용성 확인

검색 등록 전에 실제 사업자 정보, 대표 이미지, 상품 콘텐츠를 모두 확정합니다.
